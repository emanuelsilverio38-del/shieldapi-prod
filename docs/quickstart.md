# Quickstart

Base URL:

```text
https://zucchini-caring-production.up.railway.app
```

Analyze a token:

```bash
curl "https://zucchini-caring-production.up.railway.app/analyze?token=BONK&key=YOUR_API_KEY"
```

Fast cache lookup:

```bash
curl "https://zucchini-caring-production.up.railway.app/analyze-fast?token=BONK&key=YOUR_API_KEY"
```

Check usage:

```bash
curl "https://zucchini-caring-production.up.railway.app/usage?key=YOUR_API_KEY"
```
